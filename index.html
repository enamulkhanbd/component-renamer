File Format Specifications

The plugin accepts CSV or JSON files matching your current component names with the target names and descriptions.

current_name,new_name,description
"Button / Primary","Button / Default","Primary button for forms"
"Input/Text","Input/Default","Standard text input field"
[
  {
    "current_name": "Button / Primary",
    "new_name": "Button / Default",
    "description": "Primary button for forms"
  },
  {
    "current_name": "Input/Text",
    "new_name": "Input/Default",
    "description": "Standard text input field"
  }
]

Local Development Setup

To run this plugin locally inside Figma, build the source files by following these steps:

# 1. Clone the repository
git clone https://github.com/enamulkhanbd/component-renamer.git
cd component-renamer

# 2. Install development packages
npm install

# 3. Build & watch for edits
npm run watch

How to Import into Figma

  1. 1
    Open Figma: Make sure you're on the Figma Desktop application.
  2. 2
    Navigate to Development: Go to menu Plugins → Development → Import plugin from manifest....
  3. 3
    Select manifest.json: Find the manifest.json in this project folder.
